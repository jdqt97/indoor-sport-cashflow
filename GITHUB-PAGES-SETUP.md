# 🚀 GitHub Pages - Activación en 2 Minutos

Tu plataforma ya está en GitHub. Solo necesitas activar GitHub Pages.

## ⚡ Paso 1: Ve a tu Repositorio

1. Abre: https://github.com/jdqt97/indoor-sport-cashflow
2. O busca tu repositorio en GitHub

## ⚡ Paso 2: Activa GitHub Pages

### Opción A: Vía Web (Recomendado)

1. En tu repositorio, ve a **Settings** (Configuración)
   ![Step 1](https://imgur.com/example.png)

2. Baja a la sección **"Pages"** (en el menú izquierdo)
   ![Step 2](https://imgur.com/example.png)

3. En **"Source"**, selecciona:
   - Branch: **`master`**
   - Folder: **`/ (root)`**

4. Haz clic en **"Save"**

5. ¡Listo! GitHub te mostrará tu URL:
   ```
   https://jdqt97.github.io/indoor-sport-cashflow/
   ```

### Opción B: Vía Línea de Comandos

```bash
# Si tienes GitHub CLI instalado:
gh repo edit --enable-pages --source=master

# Espera 1-2 minutos a que se active
```

## 🆘 Si No Funciona

**Problema**: "No encuentro Settings"
- Busca en la barra superior del repositorio

**Problema**: "No veo la sección Pages"
- Baja más en Settings (está al final)

**Problema**: "URL no funciona después de 2 min"
- Espera 5 minutos más (a veces tarda)
- Recarga la página (Ctrl+F5)
- Abre en incógnito (descarta caché)

**Problema**: "Error 404"
- Verifica que el nombre sea exacto:
  ```
  https://jdqt97.github.io/indoor-sport-cashflow/
                     ↑ tu usuario
  ```
